### The short version

I design and build software across backend systems, Android, developer tooling, and AI-assisted workflows. I care about **what a product should do**, **why its architecture exists**, and **how its behavior can be verified**.

Java and Kotlin are my primary languages. I choose tools to serve the problem, not the other way around.

### How I think about building

<img src="https://raw.githubusercontent.com/mehmetarslanca/mehmetarslanca/main/assets/method.svg" width="100%" alt="Engineering flow: Problem, Intent, Boundaries, Architecture, Build, Evidence" />

**Understand the behavior before choosing the mechanism.** A working prototype is useful evidence, not automatic proof that the architecture was right. Clear contracts, isolated experiments, honest failure reports, and real-world verification matter more than architectural fashion.
